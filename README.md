## 🌟 Overview

**FellaRide** is a community-first mobility platform built to solve the cold-start problem in ridesharing. Rather than relying on expensive broadcast advertising or high platform commissions, FellaRide activates localized commuter networks through natural social anchors and high-overlap corridors.

### Core Modules

- **Command Center**: Macro bird's-eye view of communities, connectors, and active corridors.
- **Community Radar**: Prioritization engine highlighting high-potential neighborhoods and commute overlap.
- **Connector Intelligence**: Profiles and activates trusted local catalysts to seed organic adoption.
- **Ghost Demand**: Anticipates seat shortages and transit bottlenecks before they occur.
- **Community Activation**: Step-by-step launchpad transforming a single connection into a self-sustaining network.
- **Butterfly Effect**: Interactive growth ripple visualization illustrating the organic cascade: `1 → 3 → 8 → 17 → 32`.
- **Community Health**: Real-time vitality index tracking participation, supply ratios, and repeat usage.
- **Find a Ride & Offer a Ride**: Direct fuel-sharing between verified peers with 0% platform commission.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom Stitch design tokens
- **Routing**: React Router DOM (v7)
- **Icons**: Google Material Symbols Outlined
- **State**: React Context API + Local Storage persistence

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Abhinandan-03/fellaride-ignition.git

# Navigate into the directory
cd fellaride-ignition

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the application.

### Production Build

```bash
npm run build
npm run preview
```
